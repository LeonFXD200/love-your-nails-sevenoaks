# Love Your Nails — Sevenoaks concept

A responsive concept website and working appointment-request demo for Love Your Nails in Sevenoaks.

## What it includes

- Treatment-led landing page
- Interactive three-step appointment flow
- Local browser storage for demo requests
- Staff diary demo
- Mobile and desktop layouts
- Accessible keyboard and reduced-motion support

The booking flow is intentionally labelled as a concept. It does not contact the salon or collect data outside the visitor's browser.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Going live

Before production use, confirm the salon's exact address, opening hours, treatment menu, timings, prices, brand assets, privacy wording, and preferred booking/calendar provider.
